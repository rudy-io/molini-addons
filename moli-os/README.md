# Moli OS (add-on)

Moli OS à côté de Home Assistant, sur la même box. Configuration : `moli.toml` dans le dossier
de l'add-on (`/addon_configs/<id>_moli_os/`), données dans le volume privé de l'add-on.
Tableau de bord : `http://<adresse de la box>:8790`.
Documentation : https://github.com/rudy-io/moli-os
